# ShopZen — Modern E-Commerce Frontend

A modern, responsive e-commerce frontend built for a Bangladeshi grocery shopping experience using HTML, CSS, and Vanilla JavaScript.

Live link: https://nafisaalicodes.github.io/ShopZen-E-Commerce-Frontend-Project/
## Features

*  36 products across 6 grocery categories
*  Real time search & category filtering
*  Interactive shopping cart with quantity control
*  Wishlist functionality
*  Quick view product modal
*  Demo Login & Signup
*  Multi step Checkout — Shipping → Payment → Review
*  Order history
*  Persistent data using LocalStorage
*  Modern animations & interactive UI
*  Fully responsive design
*  Accessibility friendly with reduced motion support

## Tech Stack

* HTML5 — Semantic structure
* CSS3 — Responsive design, Grid, Flexbox & animations
* JavaScript (ES6) — Application logic & DOM manipulation
* LocalStorage — Client-side state persistence
* Google Fonts — DM Sans & Manrope

* Responsive UI development
* CSS animations & transitions
* IntersectionObserver for scroll animations

## Note

This is a frontend only project. It does not include a  backend, database, authentication system, or payment gateway. Login, cart, wishlist, and order data are stored in the browser's localStorage.
